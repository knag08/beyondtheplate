# Drop new photographs here

This folder is a staging area, ignored by git. Copy new photographs into it — any
filenames are fine — and they can then be reviewed, named, captioned and moved into
`src/assets/photos/`, where the gallery picks them up.

Why the detour: macOS privacy protection stops the tooling on this machine from reading
`~/Downloads` and `~/Desktop`, and photographs pasted into a chat are not files on disk at
all. Anything inside the project folder is readable, so this is the one reliable handover
point.

Once a batch has been moved into `src/assets/photos/`, this folder can be emptied.
